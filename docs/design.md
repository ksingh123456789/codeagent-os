# AI Code Agent Platform --- UI/UX & Technical Design

## 1. Purpose

Build a multi-portal AI Coding Agent platform with **three completely separate web portals**:

1.  **Super Admin Portal** --- platform owner
2.  **Tenant Admin Portal** --- organization/company administrator
3.  **Developer Portal** --- individual developer who receives and executes Jira tickets using GitHub and an AI coding agent

The reference design supplied for this project should be treated as the visual/product baseline, but the final application must separate the three portals into independent applications with independent navigation, authentication entry points, branding areas, and development ports.

### Core technology

-   Frontend: **React 19.3 + TypeScript**
-   Build tool: **Vite 8.x**
-   UI: Material UI (MUI) or an equivalent reusable component system
-   Routing: React Router
-   Server state: TanStack Query
-   Local UI state: Zustand where required
-   Backend: **Python + FastAPI**
-   Database: PostgreSQL
-   Cache / queue: Redis
-   Background jobs: Celery/RQ or equivalent worker architecture
-   AI orchestration: LangGraph + LangChain
-   AI tracing/observability: LangSmith
-   External integrations: Jira, GitHub, email
-   Authentication: JWT/session-based authentication with secure HTTP-only cookies preferred
-   GitHub developer login: OAuth 2.0
-   API style: REST/JSON
-   API documentation: OpenAPI generated by FastAPI
